# Jayan Vidanapathirana · Portfolio

Personal portfolio site built with React 18 (Create React App).

## Editing content

All content lives in [`src/portfolio.js`](src/portfolio.js): profile, about, experience,
projects, skills, certifications and education. Set `display: false` on a section to hide it.
Styles and theme colours are CSS variables at the top of [`src/styles.css`](src/styles.css).

## Development

```bash
npm install
npm start        # dev server on http://localhost:3000
npm test         # smoke test
npm run build    # production build in ./build
npm run format   # prettier
```
